# rswitcher

Минимальный автоматический переключатель русской/английской раскладки для macOS
на Apple Silicon. Приложение живет в строке меню, хранит только текущее слово и
не использует сеть.

## Запуск

```bash
swift run rswitcher
```

При первом запуске macOS запросит доступ в **System Settings → Privacy & Security
→ Accessibility**. После выдачи доступа перезапустите приложение.

Неверно набранное слово исправляется после пробела или знака препинания. Например:

- `ghbdtn` → `привет`
- `руддщ` → `hello`

Переключение можно временно отключить через значок клавиатуры в строке меню.

### Словарь слов

Для повышения точности используется словарь известных слов. При исправлении,
если конвертированное слово есть в словаре целевого языка — оно исправляется
с высокой уверенностью.

Добавить слово в словарь можно через меню:
- **Добавить последнее слово** — сохраняет слово, которое только что было исправлено
- **Добавить слово вручную** — ввод произвольного слова

Словарь хранится в `~/Library/Application Support/TinySwitcher/words.json`.

## Сборка

```bash
swift build -c release
swift test
```

Готовый исполняемый файл: `.build/release/tiny-switcher`.

Это первая компактная версия: она использует эвристику частых сочетаний букв,
поэтому намеренно исправляет только слова с высокой уверенностью.
