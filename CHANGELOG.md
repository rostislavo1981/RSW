# Changelog

## [Unreleased]

### Fixed
- `autoSwitchEnabled`: тумблер меню и настройка были рассинхронизированы —
  теперь `KeyboardMonitor.isEnabled` читает единый источник правды из `AppSettings`,
  меню отражает сохранённое состояние при старте
- `showTooltip`: настройка не была подключена — теперь при исправлении в иконке
  строки меню кратко показывается результат
- `launchAtLogin`: тумблер был пустышкой — теперь автозапуск регистрируется через
  `SMAppService` (для подписанного `.app`-бандла), состояние синхронизируется с системой

### Docs
- README приведён в соответствие с кодом: имя `rsw`, путь словаря `RSwitcher/`,
  команда тестов `swift run TestRunner`, версия 0.2.1
- `.DS_Store` исключён из репозитория и добавлен в `.gitignore`

## [0.2.1] — 2026-06-15

### Added
- Набор тестов `TestRunner` (266 тестов, 100%), не зависящий от XCTest

### Changed
- Проект и исполняемый файл переименованы в `RSW` / `rsw`

### Fixed
- Исправлена обработка синтетических событий CGEvent (защита от рекурсии event tap)

## [0.2.0] — 2026-06-15

### Added
- Окно настроек (SwiftUI): основные, горячие клавиши, исключения, словарь
- AXUIElement для замены текста (вместо CGEvent.post)
- Исключённые клавиши не сбрасывают текущее слово
- Минимальная длина слова для автоисправления
- Горячая клавиша для ручного переключения выделенного текста
- Вкладка словаря в настройках

## [0.1.0] — 2026-06-15

### Added
- Автоматическое определение неправильной раскладки (EN↔RU)
- Исправление слов по эвристике частотности биграмм
- Словарь известных слов для повышения точности
- Ручное добавление слов в словарь через меню
- Добавление последнего исправленного слова в словарь
- Переключение раскладки через Carbon TIS API
- Меню-бар приложение (macOS, Apple Silicon)
- Toggle вкл/выкл автопереключения
- Запрос Accessibility-доступа
- Сохранение регистра при исправлении
- Обработка Backspace для удаления символов
- Игнорирование слов с модификаторами (Cmd, Ctrl, Alt)
- Сохранение словаря в `~/Library/Application Support/RSwitcher/words.json`

### Technical
- Модульная архитектура: SwitcherCore (логика) + RSW (UI)
- CGEvent tap для перехвата клавиш
- Минимальный размер приложения
- Нет сетевых запросов, приватность пользователя

## Planned
- Поддержка дополнительных раскладок
- Настройки порога уверенности
