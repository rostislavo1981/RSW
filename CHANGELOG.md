# Changelog

## [Unreleased] — 2026-07-02

### Fixed
- Полностью удалён synthetic fallback из ручного переключения последнего
  слова: `KeyboardMonitor.manualSwitchLastWord()` теперь работает только через
  AX. Если AX не подтверждает диапазон, в логе пишется `manual_switch_failed`
  с `reason: ax_unavailable` и ничего не меняется.
- Удалён мёртвый терминальный буферизованный путь:
  `handleBufferedTerminalInput()`, `focusedAppPrefersSyntheticReplacement()`,
  `focusedAppPrefersBufferedReplacement()`. В `handle()` терминалы уходят в
  ранний return, поэтому эти функции никогда не вызывались.
- Удалены вспомогательные методы `replaceWordViaSyntheticEvents()`,
  `postKey()`, `postText(_:source:)` и `distanceFromCursorToWordStart()` —
  они были нужны только для synthetic fallback.
- Унифицирована диагностика ручного переключения: события, которые раньше
  логировались как `manual_switch_fallback` с `reason`, теперь логируются как
  `manual_switch_failed` с теми же причинами (`no_focused_ax`, `no_selection`,
  `ax_set_failed`, `no_conversion`, `empty_or_no_conversion`, `ax_unavailable`).
- В авто-пути для терминалов теперь явно пишется `correction_failed` с
  `reason: terminal_excluded` (раньше возвращался `false` без события).

### Tests
- Добавлены секции регрессионных тестов `15–17` в `TestRunner`:
  FP-русских-слов из логов (структуру/будут/буфер/машины/манипулятора и
  другие неоднозначные), TP-пар из логов и проверка встроенного EN-словаря
  (`hello`, `world`, `test`, `mac`, `switch`, `buffer`, `keyboard`).
- Всего тестов: 302 (было 273), 100% успех.

### Documentation
- Обновлена документация по безопасной архитектуре и добавлен план
  рефакторинга: `docs/REFACTORING_PLAN.md`.

## [0.2.17] — 2026-06-25

### Fixed
- Полностью удалены pasteboard fallback-пути из `KeyboardMonitor`: RSW больше не
  подменяет общий буфер обмена и не вызывает пункт меню Paste для исправлений.
- Автоисправление больше не использует неподтверждённый synthetic fallback. Если
  AX не дал прочитать и заменить слово перед курсором, исходный ввод остаётся
  без изменений, а в диагностике пишется `correction_failed` с причиной
  `ax_unavailable`.
- Ручное переключение последнего слова больше не делает synthetic backspace
  вслепую: fallback разрешён только когда AX подтвердил расстояние от курсора
  до начала слова.
- Ужесточено автоопределение русских слов: корректные слова из логов
  (`структуру`, `будут`, `буфер`, `машины`, `манипулятора`) больше не
  конвертируются в английскую раскладку.

## [0.2.16] — 2026-06-19

### Fixed
- Исправлен баг `distanceFromCursorToWordStart`: функция возвращала позицию
  слова в строке вместо расстояния от курсора до начала слова. Это приводило
  к неверному количеству backspace при синтетической замене в fallback-пути
  ручного переключения. Если перед словом был пробел (короткое слово → пробел →
  double-Option) или другой текст, backspace удаляли лишние символы, оставляя
  первые буквы слова нетронутыми.
- Убрана асинхронность (`DispatchQueue.main.async`) из автоисправления и
  ручного переключения. Раньше между поглощением keystroke и отправкой
  синтетических backspace/proper replacement была задержка, за которую
  пользователь успевал набрать новые символы — backspace удаляли уже не
  исходное слово, а текст, набранный после. Теперь замена выполняется
  синхронно в event tap callback, до обработки следующего keystroke.

## [0.2.15] — 2026-06-17

### Added
- Добавлен длительный диагностический режим `RSW_DIAG=1` со структурированными
  JSONL-логами в `~/Library/Logs/RSW/`.
- Добавлена ротация диагностических логов по размеру (`RSW_DIAG_MAX_MB`, по
  умолчанию 25 MB).
- Добавлен режим полного захвата текста `RSW_DIAG_CAPTURE_TEXT=1` для локальной
  диагностики клавиатуры, текущего слова, выделения и AX-контекста.

### Diagnostics
- Логируются клавиатурные события, активное приложение, AX-фокус, решения
  обработчика, пути автоисправления, ручное переключение, event tap и
  периодические snapshots памяти/CPU-времени.
- По умолчанию текст ввода и AX-заголовки редактируются: пишутся длины или
  redacted-значения. Полный текст пишется только при `RSW_DIAG_CAPTURE_TEXT=1`.

## [0.2.14] — 2026-06-17

### Changed
- RSW полностью отключён в терминальных приложениях: Terminal, iTerm2, Warp,
  Ghostty, Kitty и Alacritty.
- В терминалах больше не выполняются автоисправление, ручное переключение,

- При фокусе в терминале `KeyboardMonitor` сбрасывает текущее слово и пропускает

## [0.2.13] — 2026-06-17

### Fixed
- Для терминалов включён буферизованный ввод слова: буквы не отправляются в
  терминал сразу, а вставляются одним фрагментом после пробела или знака
  препинания.
- Если слово требует исправления, в терминал вставляется исправленное
  `слово + разделитель`; если не требует, вставляется исходное
  `слово + разделитель`.
- Такой режим убирает необходимость удалять уже напечатанное слово в prompt,
  что было ненадёжно через AX, pasteboard с управляющими символами, `Ctrl+W`
  и synthetic backspace.

## [0.2.12] — 2026-06-17

### Fixed
- В терминалах RSW больше не гасит исходный разделитель до замены. Пробел или
  знак препинания сначала доставляется в терминал штатно.
- Терминальная замена теперь выполняется после доставки разделителя: RSW
  пытается выделить слово перед разделителем и вставить исправление поверх него.
- Если подтверждённая замена не получилась, строка терминала остаётся как есть:
  без дубликатов исправления и без съеденного пробела.

## [0.2.11] — 2026-06-17

### Fixed
- Для терминалов отключены обычный AX fallback и synthetic fallback после
  неудачной терминальной замены. Эти пути могли вставлять исправление рядом с
  исходным словом, съедать пробел или уводить курсор.
- Если терминальный pasteboard fallback не подтвердил замену, RSW теперь
  возвращает исходный разделитель и не меняет слово вслепую.

## [0.2.10] — 2026-06-17

### Fixed
- Терминальный pasteboard fallback больше не использует `Ctrl+W`: в некоторых
  терминалах синтетическая команда удаления не доставлялась или работала
  непредсказуемо.
- Для терминалов RSW теперь сначала выделяет предыдущее слово через AX selected
  text range, затем вставляет исправленный текст поверх выделения.
- Если выделение слова в терминале установить не удалось, RSW не вставляет
  исправление вслепую, чтобы не создавать дубли, мусорные символы и уход курсора.

## [0.2.9] — 2026-06-17

### Fixed
- Терминальный pasteboard fallback больше не вставляет `DEL`-символы. Терминалы

- Ручное переключение выделенного текста получило pasteboard fallback: если
  `AXValue` не writable, RSW пробует вставить конвертированный текст поверх
  текущего выделения и после этого переключает раскладку.

## [0.2.6] — 2026-06-16

### Fixed
- Автоисправление теперь гасит исходный пробел/разделитель и само вставляет
  исправленное `слово + разделитель`. Это убирает зависимость от порядка между

## [0.2.5] — 2026-06-16

### Fixed
- Автоисправление больше не заменяет `слово + разделитель`. Теперь AX меняет
  только слово перед курсором и учитывает, успел ли пробел/знак препинания уже
  попасть в поле. Это убирает пропадающий пробел перед словом и лишние символы
  после исправления.
- Ручное переключение выделенного слова оставляет результат выделенным, поэтому
  повторное double-Option переключает слово обратно.
- Ручное переключение последнего слова сохраняет новое слово как последнее,
  поэтому повторное переключение больше не срабатывает только один раз.
- Подробные runtime-логи переведены за флаг `RSW_DEBUG=1`, чтобы запуск из
  Терминала не загрязнял AX-буфер и не мешал исправлению в терминальных окнах.

## [0.2.4] — 2026-06-16

### Fixed
- AX-замена теперь использует позицию курсора (`kAXSelectedTextRangeAttribute`)
  и заменяет диапазон непосредственно перед курсором, а не хвост всего поля.
- Ручное переключение выделенного текста читает AX selected text range вместо
  ошибочного приведения `kAXSelectedTextAttribute` к `NSRange`.
- Запись исключённых клавиш в настройках теперь реально включает перехватчик
  нажатия и не перезаписывает настройку ручной горячей клавиши.
- Режим ручной горячей клавиши теперь поддерживает обычную клавишу без
  модификаторов, если пользователь явно выбрал такой вариант.
- Названия клавиш в настройках больше не строятся из hardware keyCode как из
  Unicode-кода.
- `TestRunner` больше не пишет в пользовательский словарь:
  `WordDictionary()` по умолчанию работает в памяти, а `WordDictionary.shared`
  остаётся дисковым словарём приложения.

### Privacy
- Отладочные логи больше не печатают полный AX value, исходные слова и
  исправленный текст. В логах остаются только длины, язык и коды ошибок.

## [0.2.3] — 2026-06-16

### Changed
- Замена текста переведена на **AX position-based подход**: вместо поиска слова
  в AX value (который возвращает garbled текст на macOS 26), берутся последние
  N символов из AX value и заменяются по длине. Не зависит от содержимого.
- Удалены CGEvent `postBackspaces`/`postText` как основной метод замены —
  `CGEvent.post(tap:)` не доставляет синтетические события на macOS 26.
- Удалён clipboard-based fallback (`Cmd+A` → `Cmd+C` → `Cmd+V`) —
  CGEvent клавиатурные комбинации также не доставляются на macOS 26.

### Fixed
- **Double-Option детект**: левый (keyCode=58) и правый (keyCode=61) Option
  теперь считаются одной группой — `ManualSwitchModifier.keyCodes` возвращает
  `Set<Int>` с обоими вариантами. Раньше код требовал `keyCode == rawValue`,
  что ломало детект при нажатии правого Option при настроенном левом.
- **Double-Option детект**: изменена логика с `keyCode == modifier.rawValue`
  на отслеживание состояния flag bit (`modifierWasDown`) — определение
  нажатия/отпускания теперь работает для любого модификатора независимо от keyCode.
- **AX target not found**: `NSRange(value.startIndex...range.lowerBound)` создавал
  диапазон от начала строки — исправлено на `NSRange(range, in: value)`.
- **inputSources.select()**: переключение раскладки теперь вызывается ПОСЛЕ
  замены текста, а не до — раннее переключение искажало AX value.
- `applyCorrection` принимает `language` параметр — `inputSources.select()`
  вызывается даже при ошибке AX.

### Technical
- `ManualSwitchModifier` получил свойство `keyCodes: Set<Int>` — все keyCode,
  относящиеся к группе модификатора (левый + правый).
- `replaceTailViaAX(tailLength:replacement:)` — универсальный метод замены
  последних N символов в AX value.

### Docs
- Добавлен раздел «Правила разработки» в README — обязанность обновлять
  документацию и версию после каждого изменения.
